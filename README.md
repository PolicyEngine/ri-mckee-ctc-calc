# Rhode Island Governor McKee's Child Tax Credit Analysis

This repository contains analysis of Rhode Island Governor Dan McKee's proposed state child tax credit.

## Policy Details

- **Credit amount:** $325 per child, fully refundable
- **Age eligibility:** Children under 19 years old
- **Phase-out:** Begins at $261,000 for all filing statuses
- **Personal exemption integration:** Replaces Rhode Island's existing personal exemption for dependent children under 19
